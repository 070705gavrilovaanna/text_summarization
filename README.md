# Telegram-бот для суммаризации новостей: сравнение MBart и T5

Проект по автоматическому сжатию новостных текстов. Сравниваются две модели: MBart (610M параметров) и T5 (250M параметров). Для обработки длинных текстов реализована иерархическая суммаризация (разбиение на части, сжатие каждой, объединение). Лучшая модель (MBart) развёрнута в Telegram-боте. Бот работает на Hugging Face Spaces (FastAPI + Docker).

## Результаты тестирования

| Текст | MBart | T5 |
|-------|-------|-----|
| Политика | факты точны, грамотно (382 симв., 1.8x) | галлюцинации, опечатки(344 симв., 2.0x) |
| Юриспруденция | точная передача нормы (363 симв., 1.8x) | искажение смысла(324 симв., 2.1x) |
| Научно-популярный | аналогия сохранена (239 симв., 2.9x) | потеря смысла (119 симв., 5.7x) |
| Большая новость (ИИ) | ключевые цифры сохранены (376 симв., 10.2x) | данные не получены |
| Спорт | главное выделено (240 симв., 7.8x) | бессвязный текст (570 симв., 3.3x) |

## Пример работы MBart

**Исходный текст (3837 символов):**
> Президент России Владимир Путин подписал указ о новой национальной стратегии развития искусственного интеллекта до 2030 года. Документ предполагает увеличение финансирования отрасли в 5 раз. Согласно стратегии, к 2030 году не менее 80 процентов государственных служащих должны использовать системы ИИ... (полный текст новости)

**Сжатый текст (376 символов, сжатие 10.2x):**
> Президент России Владимир Путин объявил о создании единой платформы для обучения нейросетей, которая объединит обезличенные данные из государственных информационных систем, медицинских учреждений и промышленных предприятий. Доступ к ней получат российские разработчики на безвозмездной основе.

## Выводы

- **MBart** сохраняет факты, грамматически корректен, стабилен на всех жанрах (политика, юриспруденция, наука, спорт)
- **T5** даёт галлюцинации (выдумывает факты и людей), теряет смысл на сложных текстах, грамматически нестабилен
- **T5** сильнее сжимает (до 5.7x), но ценой полной потери качества
- **Иерархическая суммаризация** обязательна для текстов длиннее 4000 символов

## Архитектура иерархической суммаризации

1. Текст разбивается на части (800 символов, перекрытие 100)
2. Каждая часть сжимается отдельно
3. Результаты объединяются
4. Если объединённый текст длиннее 400 символов - итоговое сжатие

## Параметры генерации

- `num_beams=5` - поиск шириной 5
- `repetition_penalty=1.4` - штраф за повторы
- `no_repeat_ngram_size=3` - запрет повторять 3 слова подряд
- `early_stopping=True` - остановка при завершении
